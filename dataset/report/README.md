# Датасет: Анализ уязвимостей исходного кода 

Датасет содержит результаты статического (SAST) и динамического (DAST)
анализа безопасности двух Python/Flask-проектов: самостоятельно
написанного vulnerable.py и учебного приложения VulnMart.

## Структура
- data/vulnerabilities.csv - основной датасет найденных уязвимостей (13 записей)
- data/cwe_mapping.csv - таблица сопоставления CWE с OWASP и рангом в CWE Top 25
- raw/ - исходные отчёты сканеров (Bandit, Semgrep) в txt и json
- report/expert_assessment.md - экспертная оценка и рекомендации
